# math-test
# Логика игры
Математический тест для решения арифметических заданий. Пользователь должен ввести ответы на все примеры за определенное количество времени. После запуска теста программа генерирует математические примеры и запускает таймер обратного отчета. По окончанию времени программа проверяет результат.
