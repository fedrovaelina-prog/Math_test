# math-test
# Логика игры
Это математический тест для решения арифметических заданий. Пользователь должен ввести ответы на все примеры за определенное количество времени. После запуска теста программа генерирует математические примеры и запускает таймер обратного отчета. По окончанию времени программа проверяет результат. 
# Интерфейс игры
При запуске пользователь видит 4 арифметических действия, слева и справа от него будут генерироваться рандомные цифры, после знака "=" нужно написать ответ. Сверху находится таймер. Внизу можно увидеть кнопку "Start the quiz".
<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/20219da4-5ccd-450b-b60f-fa76440c8c27" />

При нажатии на кнопку "Start the quiz" вместо знака "?" генерируются цифры и начинается обратный отсчет.
<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/ef0d7ed1-f5a9-43cc-a193-9faef2dcd8b9" />

Когда остается 5 или меньше 5 секунд, отсчет начинает гореть красным.
<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/38a92782-b31b-4117-806f-aa87ab6407a2" />

Когда запускается таймер начинаем писать ответы, при написании ответа в поле цифра "0" автоматически стирается.
<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/3fb05a64-b60d-4569-b3ef-4fde6890ac66" />

На поле где цифра "0", сбоку можно увидеть стрелки, ими также можно вводить числа. Стрелка вверх - число больше на 1, стрелка вниз - число меньше на 1.

<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/e78572ba-7f48-4141-8d3a-157c830ac179" />

Если время закончилось, но пользователь не успел решить все примеры, то появляется сообщение об окончании таймера.

<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/8196956b-7a04-40c4-9413-7cb95634ec9d" />

Если до окончания таймера пользователь успел решить все примеры правильно, то появляется сообщение о успешном завершении теста.

<img width="599" height="488" alt="image" src="https://github.com/user-attachments/assets/535d94ad-b801-4d9e-b9b9-29860211b1ca" />

При повторно нажатии на кнопку "Start the quiz", программа сгенерирует новые примеры и отсчет начнется заново.
